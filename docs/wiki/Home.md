Welcome to the Modshift wiki.

Modshift is a free Windows app that helps you manage mods for **Euro Truck Simulator 2**
and **American Truck Simulator**. You can do everything the in-game Mod Manager does, and more,
without starting the game.

## New to the app? Start here

Follow these pages in order. Each one takes only a few minutes.

1. [Installation](Installation): download the app and start it for the first time.
2. [Getting started](Getting-Started): a tour of the main window, and turning your first mod on.
3. [Installing mods](Installing-Mods): add new mods by dropping files on the window.
4. [Mod order](Mod-Order): why the order of your mods matters, and how to change it.

## Guides

- [Presets](Presets): save a mod list and use it again, or share it with friends.
