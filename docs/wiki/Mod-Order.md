This page explains why the order of your mods matters and how to change it.

## Why order matters

Some mods change the same part of the game. For example, two mods might both change the same
truck, or two map mods might both change the same road. When that happens, only one of them can
win.

**The mod higher in the Active mods list wins.** The top of the list has the highest priority.
This is the same as the in-game Mod Manager.

If you only use a few mods that don't touch the same things, the order doesn't matter much.

## How to change the order

Select a mod in **Active mods**, then:

- Drag it up or down.
- Or use the buttons next to the list:

| Button | Keyboard | Action |
|---|---|---|
| ⤒ | Alt + Home | Move to the top (highest priority) |
| ↑ | Alt + Up | Move up one place |
| ↓ | Alt + Down | Move down one place |
| ⤓ | Alt + End | Move to the bottom (lowest priority) |

Click **Apply changes** when you are done.

## What order should I use?

- **Follow the mod author's instructions.** Most big mods, especially maps such as ProMods, tell
  you exactly which order to use on their download page.
- **Small changes above big ones.** Put small mods that change one thing (a sound, a skin, a
  fix) above large mods that change many things (a map, a full traffic pack).
- **Fixes and add-ons above the mod they fix.** A patch for a map mod usually goes above that map.
- **Map files together.** Map mods often come in several parts. Keep the parts together in the
  order the author gives.

If the game crashes or something looks wrong after you add a mod, try moving it to a different
place, or turn it off to see if it is the cause.

For ProMods, the built-in *ProMods* preset already uses the right order. See [Presets](Presets).
