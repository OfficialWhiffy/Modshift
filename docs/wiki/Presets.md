A preset is a saved mod list with a name. Use presets to switch quickly between mod setups, copy
a mod list to another profile, or share your list with friends.

Click **Presets…** in the main window to open the presets window.

## Save your current mod list

1. Set up the mod list the way you want it in the main window.
2. Click **Presets…**.
3. Type a name in the box at the top, for example "TruckersMP".
4. Click **Save list of ...**.

## Use a preset

1. Choose the profile you want in the main window.
2. Click **Presets…**.
3. Select a preset and click **Apply to list** (or double-click it).
4. Back in the main window, check the list and click **Apply changes**.

Applying a preset replaces the list you are editing. Nothing is saved to the profile until you
click **Apply changes**, so you can still click **Revert**.

If a preset contains a mod you don't have, the app tells you which ones are missing and leaves
them out. If you have a different version of a mod in the preset, the app uses your version.

## Built-in presets

Two presets for Euro Truck Simulator 2 are included. They are marked **Built-in** and can't be
changed or deleted.

- **ProMods**: every ProMods package and add-on, in the right order.

You still need to download and install the mods yourself. The preset only puts them in the right
order. When a new ProMods version comes out, the built-in presets use it automatically once you
have installed it.

## Share a preset

- **Export…** saves the selected preset as a `.json` file. Send this file to a friend.
- **Import…** adds a preset from a `.json` file someone sent you.

A preset contains only the list of mods, not the mod files. Your friend needs to have the same
mods installed.

## Other buttons

- **Rename selected**: type a new name in the box at the top, select a preset and click this
  button.
- **Delete**: removes the selected preset. Your mods and profiles are not affected.
