Words you will see in the app and in this wiki.

**Active mods**
: The mods that are turned on in a profile. The game loads only these.

**Archive (`mod_archive`)**
: A folder next to the `mod` folder where the app puts mods you remove. The game ignores it. You
  can restore mods from it at any time.

**Backup**
: A copy of a profile that the app makes before every change. See
  [Backups and safety](Backups-and-Safety).

**DLC**
: Paid extra content from SCS Software, such as map expansions. Some mods need a DLC to work.

**Load order**
: The order of the active mods. When two mods change the same thing, the one higher in the list
  wins. See [Mod order](Mod-Order).

**Local mod**
: A mod in your `mod` folder, usually downloaded from a website.

**Manifest (`manifest.sii`)**
: A small file inside a mod with its name, version, author and description. Older mods may not
  have one; the app then shows the file name.

**Mod**
: An add-on that changes or adds something in the game, such as a truck, a map or new sounds.

**`mod` folder**
: The folder the game loads mods from, for example `Documents\Euro Truck Simulator 2\mod`.

**Preset**
: A saved mod list with a name. See [Presets](Presets).

**Profile**
: Your save in the game, with your company, money, progress and mod list. Each profile has its own
  mod list.

**ProMods**
: A popular free map expansion for Euro Truck Simulator 2. It comes in several files that must be
  loaded in a set order.

**`.scs` file**
: The usual file type for a mod. The game can also load mods from `.zip` files.

**Steam Cloud profile**
: A profile that Steam copies to its servers, so you can use it on several computers.

**Steam Workshop**
: The mod section in Steam. Mods you subscribe to are downloaded by Steam and appear in the app
  by themselves.

**TruckersMP**
: A free mod that lets you play online with other players. Many players use a special mod list
  for it.
